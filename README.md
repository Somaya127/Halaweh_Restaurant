# مطعم حلاوة - موقع حجز الفعاليات

## نظرة عامة
موقع لحجز الفعاليات الشتوية العائلية لمطعم حلاوة في خلدا، عمان.

## هيكل الملفات

## كيفية الاستخدام

### 1. تشغيل الموقع
- افتح ملف `index.html` في متصفح الويب
- أو استخدم Live Server في VS Code

### 2. تعديل المحتوى
- **لتعديل المحتوى**: افتح ملف `config.js` فقط
- جميع النصوص والإعدادات موجودة في هذا الملف
- لا تحتاج لتعديل الملفات الأخرى

### 3. ما يمكنك تعديله في config.js

#### معلومات المطعم
- اسم المطعم بالعربي والإنجليزي
- الوصف والموقع
- رقم الواتساب ورقم الدعم

#### تفاصيل الفعالية
- تاريخ البداية والنهاية
- الأيام المتاحة (خميس، جمعة، سبت)
- أوقات الوجبات
- السعر وعدد المقاعد

#### المحتوى
- نصوص الصفحة الرئيسية
- المميزات (يمكن إضافة أو حذف)
- آراء العملاء (يمكن إضافة أو حذف)
- رسائل الخطأ في النموذج

#### الإعدادات
- اللغة الافتراضية (عربي/إنجليزي)
- المظهر الافتراضي (فاتح/غامق)
- نمط الألوان (دافئ/بارد/طبيعي)

## المميزات

### 1. ثنائي اللغة
- العربية (RTL)
- الإنجليزية (LTR)
- تبديل سهل بين اللغتين

### 2. أوضاع العرض
- **الوضع الفاتح/الغامق**: للراحة البصرية
- **ثلاثة أنماط ألوان**:
  - دافئ (ترابي، برتقالي، بني)
  - بارد (أزرق، رمادي)
  - طبيعي (أخضر)

### 3. تصميم متجاوب
- يعمل على جميع أحجام الشاشات
- الهواتف المحمولة
- الأجهزة اللوحية
- أجهزة سطح المكتب

### 4. نموذج الحجز
- التحقق من صحة البيانات
- رسائل خطأ واضحة
- التحقق الفوري أثناء الكتابة
- التحقق من الأيام المتاحة (خميس/جمعة/سبت)

### 5. الأقسام
- Hero (الصفحة الرئيسية)
- Benefits (المميزات)
- CTA (دعوة للحجز)
- Testimonials (آراء العملاء)
- Booking Form (نموذج الحجز)
- Footer (التذييل مع روابط التواصل)
- Thank You Page (صفحة الشكر)

## نشر الموقع

### GitHub Pages
1. أنشئ repository جديد على GitHub
2. ارفع جميع الملفات
3. اذهب إلى Settings > Pages
4. اختر main branch
5. احفظ وانتظر دقائق
6. سيكون الرابط: `https://username.github.io/repository-name`

### Netlify
1. اذهب إلى netlify.com
2. اسحب مجلد المشروع
3. سيتم نشره تلقائياً
4. ستحصل على رابط مجاني

### Vercel
1. اذهب إلى vercel.com
2. استورد المشروع من GitHub
3. سيتم نشره تلقائياً

## ملاحظات مهمة

### التواريخ
- استخدم صيغة: YYYY-MM-DD
- مثال: "2026-01-20"

### رقم الواتساب
- احذف الصفر الأول
- اكتب الرقم بالصيغة الدولية
- مثال: "962799123456"

### الأيام المتاحة
- الأحد = 0
- الاثنين = 1
- الثلاثاء = 2
- الأربعاء = 3
- الخميس = 4
- الجمعة = 5
- السبت = 6
